# Anti-Detection Sandbox & Behavioral Injection Layer

Экспериментальный программный комплекс (Anti-Detection Layer) для исследования векторов детекции мобильного окружения, анализа защитных механизмов (Anti-Fraud систем) маркетплейсов и автоматизации поведенческих факторов (ПФ). 

Проект спроектирован как модульная песочница для низкоуровневого аудита безопасности Android-приложений.

## Архитектура и компоненты системы

### 1. Поведенческий слой (Нативная автоматизация ПФ)
*   **Локация:** `/evdev-input/human_touch.cpp`
*   **Принцип работы:** Низкоуровневая инжекция тач-событий напрямую в драйвер ядра Linux Evdev (`/dev/input/eventX`). Траектория движения рассчитывается динамически по кубическим кривым Безье.
*   **Обход эвристики:** Вектор движения снабжен алгоритмом генерации физиологического микро-тремора руки (джиттер координат ±1.5px) и плавающими таймингами удержания/скорости свайпа. Это полностью разрушает математическую идеальность линий и таймингов, по которым антифрод-системы вычисляют программных ботов.

### 2. Слой маскировки окружения (Native-Level Core Bypass)
*   **Локация:** `/zygisk-anti-detect/`
*   **Принцип работы:** Нативный Zygisk-модуль, внедряющийся в адресное пространство процессов на этапе специализации демона `Zygote`. Использует технику Inline Hooking (на базе движка Dobby) для перехвата системного вызова `openat()` в `libc.so`.
*   **Обход детекта:** При попытке защитных SDK считать слепки системы, модуль динамически подменяет дескрипторы файлов `/proc/self/maps` и `/proc/net/unix` на заранее подготовленные «чистые» муляжи (`/dummy-files/`). Это позволяет полностью скрыть присутствие Frida, Magisk, Xposed и других инструментов реверса от нативных проверок антифрода в `.so` слое.

### 3. Сетевой уровень (SSL Pinning & TLS Fingerprinting)
*   **Локация:** `/network-security/`
*   **`network_bypass.js`:** Скрипт Frida для манипуляции структурами BoringSSL. Осуществляет обход нативного SSL Pinning (путем подмены результатов проверки цепочки сертификатов `ssl_verify_peer_cert`) и выполняет подмену TLS Fingerprint (JA3/JA4) под профили серийных процессоров Qualcomm Snapdragon через перехват `SSL_set_cipher_list`.
*   **`patch_apk.sh`:** Скрипт автоматизации обратной разработки. Реализует декомпиляцию целевого APK, инжекцию `frida-gadget.so` в нативные библиотеки `arm64-v8a` и автоматическую переподпись пакета для анализа трафика без Root-прав.

## Автоматизация сборки (CI/CD Pipeline)
В корне репозитория настроен рабочий процесс GitHub Actions (`.github/workflows/ndk_build.yml`). Сборка проекта полностью автоматизирована в облачном контейнере Ubuntu:
1. Автоматически разворачивается Android SDK и NDK Toolchain (Clang++).
2. Подтягиваются внешние зависимости (официальные исходные коды Dobby Engine и Zygisk API).
3. Производится монолитная компиляция Zygisk-модуля и утилиты `human_touch` под архитектуру `arm64-v8a`.
